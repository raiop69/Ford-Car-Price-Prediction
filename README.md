# 🚗 Ford Car Price Prediction
My first Machine Learning project — a **Ford Car Price Prediction model using Linear Regression**.
The goal of this project is to predict the price of a Ford car based on the available features in the dataset.

## 📌 Project Overview
For this project, I worked through the basic Machine Learning workflow, starting from preparing the data and ending with training and evaluating regression models.
I also wanted to see how different encoding techniques affect model performance, so I created and compared two different models.

### Models Used
1. **Linear Regression + Label Encoding**
2. **Linear Regression + One-Hot Encoding**
After training and evaluating both models, the **One-Hot Encoding approach performed better** and produced more accurate results.

## 🔬 Model Comparison
| Approach         | Model             | Performance |
| ---------------- | ----------------- | ----------- |
| Label Encoding   | Linear Regression | Lower       |
| One-Hot Encoding | Linear Regression | Better      |

The results showed me that the way we preprocess categorical data can have a noticeable impact on the performance of a Machine Learning model.
